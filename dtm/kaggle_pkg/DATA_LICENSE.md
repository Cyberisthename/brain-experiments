# Derived connectome matrices in this Kaggle package

**Included:** `griffa70_scale68_group_minimal.npz` only  
(keys: `sc_group`, `fc_group`, `fiber_length`, `names`, `hemis`, `n_lh`, `n_rh`, `scale`;
per-subject `sc_subj`/`fc_subj` and the raw `.mat` are **not** included)

**Source:** Griffa, Alemán-Gómez & Hagmann (2019), Zenodo record 2872624  
https://zenodo.org/records/2872624 — DOI 10.5281/zenodo.2872624  

**License:** Creative Commons Attribution 4.0 (CC BY 4.0)  
This package is intended for a **private** Kaggle dataset only.  
Cite: Griffa et al. 2019. Do not redistribute the raw Individual_Connectomes.mat.

Fiber-length consensus fields are the same Lausanne-family group matrices used in
the local `griffa70_scale68_whole.npz` derivation (group averages only).
