# Implementation lock (before first system outcomes)

This operationalizes the unchanged PREREG.md; it does not alter its hypotheses, eight seeds, metrics, multiplicity correction, or win rule.

- Snapshot raw `text` from the two permitted chat_rag knowledge files. Drop stored `question`, `answer`, `fact_statement`, and all grading metadata from the system input. IDs are provenance/tie-break keys only.
- Use transparent numeric clause-prefix slots and literal author/capital sentence patterns. No neural extraction, fine-tuning, or oracle uncertainty labels. Weak flags use source-text uncertainty words. This is a deliberately constrained motif test, not general natural-language understanding.
- Freeze 92 source-backed template questions: 52 direct, 31 hops, 7 superficially similar metric lures, 1 existing conflict probe, 1 existing weak probe. No new scientific facts are fabricated. Gold values use exact source spans; abstention labels use text rules. Same notes were used in earlier development, so these are not independent human/held-out-source validation.
- Primary hop facts must occur in the same source card and the seed uniquely identify that card within its topic. At most five ordered pairs per card, chosen by deterministic SHA256 order. Eight source cards form seven conservative topic clusters (all NEURON-4 cards together). There are no hard cross-document chains in this corpus.
- Historical 30Q author topics are conservatively excluded from primary questions; original facts remain retrieval distractors. Fictional novel/upload stories are not gold. Dictionary cards are not gold. Dataset exclusions and source references are recorded in dataset_audit.json/questions.json.
- Every arm gets the same lexical top-12 cards and extracted facts. Bag performs local span extraction within retrieved seed cards, a stronger baseline than forcing all hop questions to abstain. Graphs use only three-hop paths inside the same candidate-card budget, never a global entity-table join. A tie with this simple baseline is not a reasoning win.
- Association links are explicit same-card cliques, same-slot agreement/conflict across cards, and similar slot tokens across different raw-text topics marked unrelated_similar. No dated update/supersession examples exist in these selected cards; that subtype is not tested.
- Plain graph uses ordinary extraction. E and both shuffle controls use the identical boundary policy: block unrelated_similar; downweight uncertain_source; reject only-weak support/unresolved conflicting values. Candidate readout is identical between E and the shuffle arms. Direct questions have literal slot cues; association questions hide the target card and require matching a seed field.
- Endpoint shuffle uniformly permutes all undirected edge stubs, preserving each named node's degree, link count, and label multiset exactly. Self-loops/multiedges are retained and audited. Label shuffle permutes the full typed label multiset with endpoints unchanged. Existing N3 B/C were inspected but not reused: this local prose adapter also avoids the inherited hop solver's second retrieval bypass.
- Fixed seeds 0..7. Bag/plain/E are deterministic; repeats only align paired summaries. Source-cluster inference averages seeds before sign flips, and Holm corrects H1/H2. H3 remains unadjusted exploratory. Guardrails follow the locked preregistration exactly. Nominal confidence is uncalibrated; all wrong non-abstaining answers count as confident-wrong.
- Five mechanical fixture tests verify decimal extraction, source offsets, degree/label preservation, graph-path necessity, source-text weak abstention, and rejection of grading metadata. No dataset prediction was inspected while writing or tuning this implementation.
- No production imports or modifications; no source repository operation, external services, QPU, or training. CPU-only standard library, nice 19, one numerical-library thread. All output under neuron/reason. All neuron4 files and JARVIS answer-path files checked by SHA256 before and after.

The earlier unrun report will be archived under status_before_run/. Local execution availability changed, not the scientific preregistration. Once frozen_manifest.json is written, no code/data/settings changes are permitted without a versioned bug amendment and retention of the old run.
