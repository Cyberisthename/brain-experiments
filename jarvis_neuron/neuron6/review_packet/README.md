Nothing here is reviewed. Any item with "status": "UNREVIEWED" is NOT valid test ground truth.
Roles: annotator A, annotator B (independent, do not discuss), adjudicator, blind answer grader. Builders may not take these roles.
Per item, annotators fill: label (answerable/conflict/insufficient), category C1-C7, gold value + unit + context + valid-time, relation type per evidence pair
(supports / contradicts / supersedes(corrects) / different-context / unrelated-similar / weak-evidence), source reliability (high/medium/low + reason),
whether sources are independent (same origin?), confidence 1-5, free-text note. Do not look at any system output.
